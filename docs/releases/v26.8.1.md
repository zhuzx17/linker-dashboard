# Linker Dashboard v26.8.1

当前推荐版本，增加局域网多人控制、账号云服务、BLE 无屏配网和 Android App。

## 主要更新

- 新增云端账号认证、控制器注册和 WebSocket 指令中继。
- 支持控制器主动连接公网云服务，无需为树莓派开放入站端口。
- 局域网内免配对码直接访问，并支持多个操作端共享控制和状态同步。
- 增加 BLE 无屏配网，用于配置 Wi-Fi、云账号和控制器信息。
- 增加 Android、iOS 移动端工程以及局域网发现、云端登录和蓝牙配置界面。
- 增加 Linux systemd、Windows 开机自启、云服务和树莓派部署工具。
- 更新 Android 与 iOS 应用图标和启动页品牌资源。

## 下载说明

- Linux 提供 amd64、arm64 压缩包，包含控制台、云服务和安装脚本。
- Windows 提供 amd64、arm64 压缩包，包含控制台和开机自启脚本。
- Android 提供可直接安装的调试签名 APK。
- 使用 `SHA256SUMS` 校验所有主要下载文件。

## 连接说明

- 局域网控制无需安全码，不限制接入数量。
- 公网控制通过账号和云端 WSS 中继。
- BLE 仅用于首次配网和账号配置，不承载实时运动控制。

> Android APK 当前使用调试证书签名，适合测试和展会环境，不是应用商店正式签名版本。
