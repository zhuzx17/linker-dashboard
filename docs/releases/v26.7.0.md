# Linker Dashboard v26.7.0

首个统一提供四平台归档与完整校验文件的公开分发版本。

## 主要更新

- 提供 Linux amd64、Linux arm64、Windows amd64、Windows arm64 安装包。
- 控制台单二进制内嵌前端、型号描述、手势和手势舞资源。
- `gocan` 更新到 `v1.0.0`，`socketcan-init` 更新到 `v1.0.1`。
- 发布包附带独立 `.sha256` 和汇总 `SHA256SUMS`。

## 下载说明

- Linux amd64：常见 x86-64 Linux 主机。
- Linux arm64：树莓派等 64 位 ARM Linux 主机。
- Windows amd64：常见 Intel/AMD Windows 主机。
- Windows arm64：ARM64 Windows 主机。

下载后请使用 `SHA256SUMS` 校验文件完整性。
