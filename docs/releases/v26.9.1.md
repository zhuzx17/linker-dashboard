# Linker Dashboard v26.9.1

本版本为依赖安全修复版本，基于 Gitea 主项目最新 `main` 构建。

## 修复内容

- 升级 `browserslist` 至 4.28.8，修复 npm audit 报告的高危漏洞。
- 升级 `@xmldom/xmldom` 至 0.9.12，修复 XML 片段注入中危漏洞。
- 前端测试、TypeScript 构建和 Go 全量检查通过。

## 下载内容

- Linux amd64、Linux arm64 控制台压缩包。
- Windows amd64、Windows arm64 控制台压缩包。
- Android debug APK（调试签名，适合现场测试和内部使用）。
- 每个文件对应的 `.sha256` 校验文件及汇总 `SHA256SUMS`。

## 校验与使用

下载后请先使用 `sha256sum -c SHA256SUMS` 校验文件完整性，再参考仓库中的安装、移动端和故障排查教程。
