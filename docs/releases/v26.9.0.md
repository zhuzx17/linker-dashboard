# Linker Dashboard v26.9.0

本版本引入剪刀石头布必胜模式、经典 CAN 全功能码控制、Gesture/Dance 全链路与 CAN 帧日志，
并升级上游 Go 依赖；发布包随包携带 MiniCANFD 动态库。

## 主要更新

- 全型号剪刀石头布必胜模式与高频视觉跟踪。
- 经典 CAN 全功能码控制（L6、O6、O7、L10、L20Lite、L20）与前端功能码面板。
- Gesture 与 Dance 全链路：多型号手势数据模型、手势舞执行引擎与实时状态同步。
- CAN 帧日志（RX/TX）与多维过滤、明暗主题、Overview 四段式重构。
- 上游 Go 依赖升级至 `gocan v1.1.0` 与 `socketcan-init v1.1.0`。

## 发布包内动态库

- Linux amd64：`libcanbus.so`
- Linux arm64：`libcanbus_arm64.so`
- Windows amd64：`HCanbus.dll`
- Windows arm64：不含动态库（无对应架构 DLL）

## 下载说明

- Linux 提供 amd64、arm64 压缩包。
- Windows 提供 amd64、arm64 压缩包。
- Android 提供可直接安装的调试签名 APK。
- 使用 `SHA256SUMS` 或随包 `.sha256` 文件校验下载内容。
