# Linker Dashboard v26.8.0

这是接入云端服务器与移动端配对功能前的最后一个稳定版本。

## 主要更新

- 增加全型号剪刀石头布必胜模式与高频视觉跟踪。
- 补齐经典 CAN 功能码控制与状态查询界面。
- 增加中英文界面切换并优化主题、日志和交互反馈。
- 修复前端依赖安全告警，发布时依赖审计为 0 个已知漏洞。
- 提供 Linux、Windows 的 amd64 与 arm64 四个平台安装包。

## 下载说明

- Linux amd64：常见 x86-64 Linux 主机。
- Linux arm64：树莓派等 64 位 ARM Linux 主机。
- Windows amd64：常见 Intel/AMD Windows 主机。
- Windows arm64：ARM64 Windows 主机。
- 使用 `SHA256SUMS` 或对应的 `.sha256` 文件校验下载内容。
