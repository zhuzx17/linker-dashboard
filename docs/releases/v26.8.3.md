# Linker Dashboard v26.8.3

本版本统一调整控制台默认端口，并同步各平台安装、发现和开发配置。

## 主要更新

- 将控制台默认监听端口从 `8080` 调整为 `7081`。
- 同步 Vite 开发代理、Linux systemd、Windows 开机自启和树莓派部署健康检查。
- 将 Linux 与 Windows 防火墙放行规则调整为 TCP `7081`。
- 更新移动端手动地址提示以及公开安装、移动控制和故障排查说明。
- 保留通过 `--addr` 或 Windows `-Port` 参数自定义监听端口的能力。

## 下载说明

- Linux 提供 amd64、arm64 压缩包，包含控制台、云服务和安装脚本。
- Windows 提供 amd64、arm64 压缩包，包含控制台和开机自启脚本。
- Android 提供可直接安装的调试签名 APK。
- 使用 `SHA256SUMS` 或随包 `.sha256` 文件校验下载内容。

## 升级提示

- 使用默认配置升级后，请通过 `http://<控制台 IP>:7081` 访问控制台。
- 如果已有反向代理、防火墙或固定端口脚本，请同步将其上游端口调整为 `7081`。
- 显式指定旧端口的部署仍可继续使用，不受默认值变化影响。
