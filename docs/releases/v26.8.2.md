# Linker Dashboard v26.8.2

本版本集中更新设备识别、内置动作和移动端交互，并补齐全平台发布附件。

## 主要更新

- 更新 L10、L30、O30i、O6 与 O6i 的内置手势和手势舞序列。
- 增加全型号 WRC 手势舞和剪刀石头布必胜模式。
- 修复 O6i 返回 `NONE` 时无法自动识别的问题。
- 为 O6 和 O6i 手势舞增加独立严格时间线。
- 完善 Linux 主机 BLE 发现、移动端密码提示和窄屏布局。
- 修复前端构建链的 `nanoid` 高危依赖告警。

## 下载说明

- Linux 提供 amd64、arm64 压缩包，包含控制台、云服务和安装脚本。
- Windows 提供 amd64、arm64 压缩包，包含控制台和开机自启脚本。
- Android 提供可直接安装的调试签名 APK。
- 使用 `SHA256SUMS` 或随包 `.sha256` 文件校验下载内容。

## 兼容性说明

- O6i 的 C0 查询完整返回 `NONE` 时按 O6i 识别，左右手由应答 CAN ID 判断。
- 升级后如需使用新的内置手势，应先备份运行时 data 目录，再按安装文档重新释放预设。
- Android APK 使用调试证书签名；若现有安装包签名不同，需要先卸载旧版本。
