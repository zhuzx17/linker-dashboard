# Linker Dashboard v26.9.2

本版本修复 Windows MiniCANFD 识别及连接问题，相关修复已由用户完成 Windows 真机测试。

## 更新内容

- 升级 `gocan v1.1.3`，配套新版 x64 `HCanbus.dll`，修复适配器能打开但无法识别灵巧手的问题。
- 网页服务先启动，设备扫描在后台进行；连接增加超时、重复请求保护和明确的错误提示。
- Windows amd64 包统一携带已测试的 DLL；修正发布目录，确保压缩包中包含可执行主程序。

## 下载内容

- Linux amd64、Linux arm64 压缩包，包含控制台、云端程序及对应厂商动态库。
- Windows amd64、Windows arm64 压缩包，包含 `linker-dashboard.exe`；amd64 包另含 `HCanbus.dll`。
- Android 调试 APK，可与上一版使用相同签名覆盖安装。
- 每个产物对应的 `.sha256` 文件和汇总 `SHA256SUMS`。

## 升级与使用

1. 停止旧版控制台并备份 `data` 目录。
2. 解压对应平台的发布包，同时替换主程序及随包动态库，保留原有 `data`。
3. 启动控制台，在浏览器打开 `http://127.0.0.1:7081`。

MiniCANFD 需使用 Windows amd64 包，DLL 与 EXE 放在同一目录；无需 `.h` 和 `.lib`。
Windows arm64 暂不支持厂商 MiniCANFD DLL。APK 使用调试签名，适用于现场测试和内部使用。

下载全部产物后可运行 `sha256sum -c SHA256SUMS` 校验完整性。
