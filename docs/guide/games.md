# 游戏与视觉跟随

[返回目录](../README.md)

在“游戏中心”先选择在线设备，再选择对应功能。摄像头属于正在打开页面的电脑或手机。

## 摄像头准备

允许摄像头权限，选择正确的摄像头，让整只手进入画面并保持光照。
识别模型随程序提供；出现加载失败时，确认页面资源完整，并能正常访问控制台。

电脑浏览器建议从本机 `http://localhost:7081` 或 HTTPS 页面打开。
普通局域网 HTTP 页面可能无法获得摄像头权限。
处理分辨率和频率越高，对主机性能要求越高；画面卡顿时适当降低。

## 剪刀石头布

进入剪刀石头布功能，启动摄像头后向镜头展示稳定的手势。
系统识别后向所选设备发送对应动作。
这项功能会使用手势库中的“2”“握拳”和“5”；修改这些预设会影响实物动作。

## 2D 手势跟随

1. 选择页面列出的可跟随设备。
2. 核对设备左右手，并选择摄像头。
3. 点击“启动跟随”，让手进入画面。
4. 观察关键点、目标关节和设备反馈；完成后点击“停止跟随”。

系统保留 21 个关键点并映射到设备支持的关节。是否开放实时控制以页面提示为准；
存在映射并不表示该型号已经完成真机标定。

3D 跟随仍在开发中，不应将页面入口视为已完成的控制功能。
