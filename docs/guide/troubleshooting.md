# 故障排查

[返回目录](../README.md)

## 网页打不开

先确认控制台窗口仍在运行，本机访问 <http://127.0.0.1:7081>。
若双击后窗口立即关闭，在 PowerShell 或终端运行程序，查看错误提示。
端口被占用时，可用 `--addr :7082` 启动并访问新端口。

## 主机能打开，手机打不开

确认手机和主机在同一局域网，地址使用主机 IP，不是手机的 `127.0.0.1`。
放行主机 TCP 7081；自动发现还需要 UDP 5353。
访客 Wi-Fi 或路由器的设备隔离可能阻止互访。

手动地址可以连接但扫描不到时，可先手动使用，再检查自动发现相关网络设置。

## 看不到适配器或灵巧手

1. 核对适配器驱动、灵巧手供电和 CAN 接线。
2. 新插入适配器后点击“重新连接”；已连接适配器上的手刚上电可点击“重新扫描”。
3. 关闭可能占用设备的厂家工具或其他控制台。
4. 仍失败时保存启动到连接失败的终端日志。

MiniCANFD 在 Windows 设备管理器中显示为“WinUSB 设备”可能是正常现象。
应检查设备是否运行正常，使用 windows-amd64 主程序及同一发布包中的 `HCanbus.dll`。
已发现适配器但未识别手型号时，再检查手的供电、接线和通信参数。
持续提示驱动未返回时，重启控制台后重试。

## 蓝牙扫描或配网失败

确认主机为支持蓝牙广播的 Linux 设备，手机已授予附近设备权限。
默认配网窗口为 15 分钟，过期后重启控制台。
需要写入 Wi-Fi 时，确认主机已安装 NetworkManager，网络名称和密码正确。

## 云端控制器离线

确认主机控制台正在运行，主机和手机都能访问管理员提供的云服务。
检查两端使用同一服务地址，以及主机时间是否正确。
不要通过反复删除数据目录来重试，这会改变控制器身份。

## 动作没有随升级更新

升级保留已有数据。需要新版内置动作时，按[数据管理](data.md)备份并重新生成预设。

## APK 无法覆盖安装

确认安装的是更新版本；不同签名的 APK 无法直接覆盖。
确需更换签名时，记录连接设置后卸载旧版再安装。

## 摄像头无法打开

确认已授予权限，且未被其他应用占用。浏览器使用本机 localhost 或 HTTPS 页面；
局域网 HTTP 可能被浏览器限制。详见[游戏与视觉跟随](games.md)。

## 联系售后时提供

提供控制台版本、操作系统与架构、适配器和手型号、出问题的操作步骤，以及对应日志。
分享前删去账号密码、Wi-Fi 密码、邀请码和令牌。
