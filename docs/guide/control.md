# 关节与状态控制

[返回目录](../README.md)

## 调节关节

1. 在总体控制或型号控制页面选择目标设备。
2. 将全局速度调低。
3. 拖动关节滑块，观察实物运动方向。
4. 多台同型号设备被勾选时，控制会发给这些设备。

L30 在运动控制前会按需自动使能；页面也提供使能与失能操作。
不同型号的滑块数量和功能不同，不要直接套用其他型号的关节数值。

## 读取当前位置

需要把实物位置回填到滑块时，点击全局速度后面的“读取当前位置”。
滑块不会持续被自动位置查询覆盖，以便稳定拖动和编辑动作。

多设备控制时，状态读取通常展示首个目标设备的结果。
要检查某一只手，可只勾选该设备。

## 速度、力矩与状态

页面按型号提供速度、力矩、温度、电流、错误和触觉等功能。
选择相应读取项后查看反馈；没有显示的功能表示当前型号未开放该操作。
“协议功能码”用于按设备协议执行进阶读写，使用前应确认参数含义。

## 切换运动与停止

点击新的运动会停止受影响设备上的旧运动，再执行新动作。
手势舞的“停止”会停止整场序列发送，详见[手势舞](dances.md)。

软件停止不等同于物理急停；测试前应为手部留出活动空间。

## 语言、主题与日志

右上角可以切换中英文和明暗主题。需要排障时，展开 CAN 日志，按型号、接口、方向或 ID
筛选记录；日常控制无需理解通信帧。
