# 云端账号与控制器共享

[返回目录](../README.md)

手机和控制台不在同一网络时，可以通过云服务控制。云服务地址由部署管理员提供；
App 和控制器应使用同一服务。控制器需要能访问该服务，无需固定公网 IP。

## 登录与添加控制器

1. 向管理员获取操作员注册码，在 App 中创建账号并登录。
2. 通过[蓝牙添加](bluetooth.md)关联现场控制器，或按管理员指引使用设备接入码登记。
3. 如果控制器已由其他操作员关联，可使用对方生成的控制器共享码。
4. 在控制器列表选择在线设备，进入控制页面。

账号密码至少 10 位。已经登记的控制器重启后会自动连接，不需要每次重新登记。

## 三类邀请码

| 名称 | 用途 | 提供方 |
| --- | --- | --- |
| 操作员注册码 | 注册新操作员账号 | 管理员 |
| 设备接入码 | 让控制器接入云服务并关联当前账号 | App 中具备相应权限的已登录操作员 |
| 控制器共享码 | 把已有控制器关联给另一个账号 | 已关联该控制器的操作员 |

共享码不会创建账号；应先注册并登录再使用。邀请码为临时、一次性凭据，失效后重新生成。

## 多人共享

同一控制器可关联多个账号。已关联的操作员可以操作设备，并看到同步的运行状态；
不会按账号独占某个 CAN 口。

局域网控制不依赖云账号。需要搭建服务器时，由管理员参考[自建云服务](../deployment/cloud.md)。
