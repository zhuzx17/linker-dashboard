# 手机与局域网连接

[返回目录](../README.md) · 相关：[蓝牙配网](bluetooth.md)、[云端控制](cloud.md)

## 安装 App

从[最新版本](https://github.com/zhuzx17/linker-dashboard/releases/latest)下载 APK。
在 Android 设置中允许浏览器或文件管理器安装应用，然后打开下载的 APK。
同一签名的新版本可以覆盖安装；签名不同导致安装失败时，先查看[故障排查](troubleshooting.md)。

## 连接附近控制器

1. 在电脑或树莓派上启动控制台。
2. 手机与主机连接同一 Wi-Fi 或局域网。
3. 打开 App，扫描附近控制器，选择要操作的主机。
4. 进入页面后，在设备管理中勾选灵巧手。

扫描不到时，手动输入 `http://<主机 IP>:7081`。
也可用手机浏览器直接打开该地址；浏览器无需安装 APK，但不能扫描附近服务。

局域网连接不需要登录账号或输入配对码。酒店和展会访客 Wi-Fi 可能隔离设备，
可换用允许互访的网络。

## 多人操作

多个手机、平板和浏览器可同时连接，没有软件设置的接入人数限制。
手势舞开始、停止及执行状态会同步显示；刷新页面后会恢复显示当前运行状态。

操作员共享设备控制权限，不按账号分配 CAN 口。
新运动会替换受影响设备上的旧运动，现场仍应约定好各自操作的设备。

跨网络连接请使用[云端控制](cloud.md)。
