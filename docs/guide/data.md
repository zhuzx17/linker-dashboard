# 数据备份与升级

[返回目录](../README.md)

手势、手势舞和设备设置保存在运行控制台的主机上，不保存在手机 APK 中。

## 找到数据目录

| 启动方式 | 默认位置 |
| --- | --- |
| 在解压目录启动程序 | 当前工作目录下的 `data/` |
| Linux / 树莓派安装自启服务 | `/var/lib/linker-dashboard` |
| Windows 安装自启任务 | `%ProgramData%\LinkerBot\Dashboard` |
| 显式传入 `--data` | 参数指定的目录 |

相对路径以启动程序时的工作目录为准，不一定是 EXE 所在目录。
想固定位置时，使用绝对路径的 `--data` 参数。

## 备份与升级

1. 停止控制台或自启服务。
2. 备份整个数据目录。
3. 解压新版本，同时替换主程序和随包动态库。
4. 使用原数据目录重新启动，检查设备设置和自定义动作。

普通升级保留已有动作，必要时会补齐缺失的系统动作或型号。
不要把包含云端身份的整个数据目录复制给另一台控制器使用。

## 使用新版内置动作

首次启动时，只有数据目录不存在或没有任何文件，才会释放内置手势和手势舞。
已有数据目录会继续使用本地内容，不会整套替换；程序仍会补齐部分缺失的系统预设。

需要使用全新的内置动作时，先备份并将旧数据目录改名，再启动程序。
随后按需迁移自定义动作；同名文件会覆盖新版本内容，请逐项确认。
此操作也会重新生成主机身份，云端控制器可能需要重新关联。

给研发反馈动作变化时，提供备份中的手势或手势舞文件即可。
把动作纳入源码版本的步骤放在开发者文档中。
