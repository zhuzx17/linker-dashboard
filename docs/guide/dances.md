# 手势舞

[返回目录](../README.md) · 相关：[手势编辑](gestures.md)

## 执行与停止

1. 选择目标设备。
2. 设置全局间隔、循环次数和循环间隔。
3. 点击手势舞卡片开始；运行期间点击“停止”结束整场手势舞。

循环次数为 0 表示持续循环。刷新页面或另一位操作员连接后，会显示同一场手势舞的运行状态。
新的手势舞会替换当前手势舞。

## 同时执行与滚动执行

| 模式 | 执行方式 |
| --- | --- |
| 同时 | 所有有效目标同时开始 |
| 滚动 | 按页面的型号顺序逐组开始，同型号的设备同时执行 |

滚动模式可调整型号顺序和组间隔。前一型号组完成本轮动作后，再等待组间隔开始下一组；
同组动作长短不同时，以该组完成时间为准。没有被选中或没有动作的型号不参与执行。

执行方式和型号顺序在开始前设置，运行时不可切换。

## 间隔与每轮结束动作

全局间隔控制相邻步骤的等待时间，也可为型号单独设置。
编辑器中指定了步骤持续时间的序列，优先使用步骤自身的时间。

默认每台设备完成一轮后执行手势“5”，再进入后续调度。这个收尾动作使用传入的型号间隔，
不采用手势自身的保持时间。部分专用序列可配置保持末帧，以该序列设置为准。
手势“5”应与该型号的张开姿势一致；修改后先单手验证。

## 创建与编辑

在型号控制页把多个姿势加入暂存序列，点击“保存为手势舞”。
加载已有手势舞后，可“保存修改”或“另存为新手势舞”，后者保留原项目。
保存时若提示内容已被其他操作端更新，重新加载再编辑。

## O30i 左右手

O30i 可以保存“通用”“左手”“右手”三种序列：

- 已知左右手且有对应序列时，执行对应的专用序列。
- 没有对应专用序列时，使用通用序列。
- 未指定手别且没有通用序列时，需要先在设备管理中配置左右手，才可执行。
- 已知手别但既无对应序列也无通用序列时，该设备不执行。

编辑时切换相应序列槽，再保存全部序列。实际设备手别在[设备管理](devices.md)中查看或指定。
