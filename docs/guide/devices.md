# 连接与选择设备

[返回目录](../README.md) · 下一步：[关节控制](control.md)

## 首次连接

1. 接好灵巧手电源、CAN 线和适配器，再将适配器连接主机。
2. 启动控制台，等待后台扫描完成。
3. 展开“设备管理”，核对型号、接口和左右手。
4. 勾选需要控制的设备；“全选”和“清空”可批量调整选择。

控制命令发给已勾选且在线的目标。多台手连接时，先选择一台做简单动作确认。

| 通信类型 | 型号 |
| --- | --- |
| 经典 CAN | L6、O6、O6i、O7、L10、L20Lite、L20 |
| CAN FD | L30、O20、O30i |

具体可用功能取决于型号和固件，以页面显示为准。

## 重新扫描与重新连接

| 操作 | 适用场景 |
| --- | --- |
| 重新扫描 | 适配器已打开，灵巧手刚上电或需要重新识别型号 |
| 重新连接 | 新插入 USB 适配器、更换连接或适配器需要重新打开 |

重新扫描和重新连接都会停止正在执行的动作。发现新插入的适配器时应点击“重新连接”。
连接失败会显示提示；持续提示驱动忙碌时，关闭厂家工具及其他控制台，再重启程序。

## 型号与左右手

设备区可以保存手动指定的型号和左右手，也可以恢复自动识别。
只在确认实物型号后修改；手动选择型号不能替代正确的驱动、供电和接线。

O30i 左右手分别接在不同 CAN 口时，程序会根据应答自动识别手别。
进入型号控制页后会自动选择识别到的设备，执行前仍可调整勾选范围。

未发现或未识别设备时，查看[故障排查](troubleshooting.md)。
