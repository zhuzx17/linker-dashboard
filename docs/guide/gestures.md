# 手势

[返回目录](../README.md) · 相关：[手势舞](dances.md)

手势适合保存一个姿势或一次执行的短动作，例如数字、OK、Yo 和握拳。

## 执行已有手势

1. 勾选目标设备。
2. 在手势区选择对应卡片。
3. 查看实物与执行提示；只有该手势包含动作的型号会执行。

## 创建手势

1. 进入对应型号的控制页面。
2. 调整关节到需要的姿势。
3. 点击“保存为单步手势”，输入名称并保存。

需要组合多个姿势时，依次“添加当前姿势”到暂存序列，调整步骤和保持时间，
再选择“保存为手势”。

## 编辑、保存和另存为

在手势库中加载要编辑的项目，修改步骤或关节值后选择：

| 操作 | 结果 |
| --- | --- |
| 保存修改 | 更新原名称下当前型号的动作 |
| 另存为新手势 | 输入新名称，保留原手势 |
| 转换并另存为手势舞 | 将当前动作作为手势舞另存 |

另存为时，新名称不能与原名称相同。切换编辑项目或清空未保存内容时，按页面提示确认。

删除手势会删除该名称下所有型号的动作。需要保留原动作时，先另存一个副本。

## 保存位置

手势保存在运行控制台的主机上，其他连接同一主机的操作端也会使用这份数据。
备份与升级方法见[数据管理](data.md)。
