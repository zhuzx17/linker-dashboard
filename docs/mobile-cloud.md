# 手机、局域网、蓝牙与云端控制

本功能从 v26.8.1 开始提供。BLE 用于无屏设备首次配置，不承载关节、日志或手势舞实时数据；
实际控制流量走局域网 HTTP/WebSocket 或云端 HTTPS/WSS。

## 1. 安装 Android App

1. 从 [v26.8.2 Release](https://github.com/zhuzx17/linker-dashboard/releases/tag/v26.8.2)
   下载 APK 和对应 `.sha256` 文件。
2. 核对 SHA-256。
3. 在 Android 设置中允许当前浏览器或文件管理器“安装未知应用”。
4. 安装 APK。若设备上已有不同签名版本，先备份配置并卸载旧版。

当前 APK 使用调试证书签名，仅用于测试和展会环境。

## 2. 局域网直接控制

控制台启动后会通过 mDNS 广播 `_linkerhand._tcp.local`。手机与控制台在同一局域网时：

1. 打开 App，进入附近控制器列表。
2. 选择扫描到的 LinkerBot 控制器。
3. 如果自动发现不可用，手动输入 `http://<控制台 IP>:8080`。
4. 进入控制页面后选择型号、左右手和目标设备。

局域网连接不需要配对码，也不限制操作员数量。所有客户端会接收同一份权威设备和运动状态；
一个操作员启动或停止手势舞后，其他操作员界面会同步更新。

不要把未启用 HTTPS 的 8080 端口直接映射到公网。跨互联网控制应使用云端中继。

## 3. BLE 无屏配网

适用于没有显示器和键盘的树莓派或 Linux ARM 控制器。

准备条件：

- 控制器安装 v26.8.2，并启用 BlueZ；
- 写入 Wi-Fi 时安装 NetworkManager；
- 手机开启蓝牙并允许“附近设备”权限；
- 手机已经登录 LinkerBot 云账号。

操作步骤：

1. 重启 `linker-dashboard` 服务。默认会开放 15 分钟 BLE 配网窗口。
2. App 中选择“通过蓝牙添加”。
3. 选择名称以 `LH-` 开头的控制器。
4. 控制器未联网时开启 Wi-Fi 配置，输入 SSID 和密码；已经联网时可沿用当前网络。
5. 点击配置并关联，等待 App 提示完成。
6. 回到控制器列表，设备显示在线后进入控制页面。

开放网络的 Wi-Fi 密码可以留空；加密 Wi-Fi 密码至少 8 位，云账号密码至少 10 位。v26.8.2
会在密码过短时直接显示长度要求。

BLE 窗口超时后重启控制台服务即可重新开放：

```bash
sudo systemctl restart linker-dashboard
sudo journalctl -u linker-dashboard -n 100 --no-pager
```

## 4. 云端跨网络控制

推荐结构：

```text
手机 App ---- HTTPS/WSS ----> 云服务
                                ^
控制器 ---- 主动出站 WSS ------+
```

控制器主动连接云端，因此树莓派不需要固定公网 IP，也不需要路由器端口映射。当前部署的测试
云地址为 `https://8.145.58.150`；自建云服务时在 App 和控制器环境配置中填写同一地址。

控制器首次登记成功后，凭据保存在 data 目录的 `cloud.json` 中。后续重启会自动连接，不应把
云服务器 SSH 私钥复制到控制器。

## 5. 三类邀请码的用途

| 类型 | 谁生成 | 用途 |
| --- | --- | --- |
| 操作员注册码 | 管理员 | 创建新的操作员账号；普通操作员不能邀请新账号 |
| 设备接入码 | 已登录并有权限的操作员 | 让尚未登记的控制器首次接入云端，一次性使用 |
| 控制器共享码 | 已关联该控制器的操作员 | 把已有控制器关联给另一个已存在的账号 |

设备接入码不是登录密码，控制器共享码也不会创建新账号。多个账号关联同一控制器后共享控制
权限，不按用户划分 CAN 口。

## 6. 多操作员展会模式

- 多个手机、平板或浏览器可以同时进入同一控制台。
- 后端串行处理运动切换，新动作会停止受影响设备上的旧动作。
- 手势舞的开始、停止和循环状态会同步到所有客户端。
- 现场仍应约定操作范围，避免两位操作员几乎同时向同一只手发送相反指令。

即使软件允许多人控制，也应保持机械安全距离，并为展会准备断电或急停手段。
